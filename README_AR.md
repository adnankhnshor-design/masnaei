# مصنعي — نسخة أولية من ملفات Flutter

تحتوي على واجهة عربية أولية: تسجيل دخول شكلي، اختيار مدير/عامل، وعرض 10 آلات.
أزرار المدير تغيّر حالة تجريبية داخل الشاشة فقط. لا يوجد اتصال حقيقي بالمصنع أو Opta،
ولا توجد مصادقة أو قاعدة بيانات أو خادم بعد. لا تستخدمها للتحكم الصناعي.

للتشغيل لاحقاً على كمبيوتر مجهز بـ Flutter:
1. فك الضغط وافتح المجلد في Android Studio أو VS Code.
2. نفّذ `flutter pub get`.
3. نفّذ `flutter run`.

قبل التشغيل الحقيقي يجب بناء خادم آمن، مصادقة وصلاحيات فعلية، اتصال مشفر مع Opta،
وتنفيذ اختبارات السلامة والاتصال بالمصنع.
